# LinkedIn Post - zxSnake Release

## English Version

**Just released my first retro game: zxSnake for ZX Spectrum 48K!**

As a developer, I believe creativity has no boundaries. I challenged myself to build a complete game for a machine from 1982 — written entirely in Z80 assembly language.

zxSnake features 8 hand-crafted levels, animated sprites, custom loading screen, menu music, and a New Game+ mode with infinite difficulty scaling. All packed into ~14KB of machine code.

Why build for a 40+ year old platform? To face real hardware constraints, get back to the roots of programming, and prove that the passion for creating goes beyond everyday frameworks.

Play it free: https://marekpi.itch.io/zxsnake
